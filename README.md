# nur

Nix User Repository for [baryon-mcp](https://github.com/combor/baryon-mcp).

```sh
nix-env -f https://github.com/combor/nur/archive/main.tar.gz -iA baryon-mcp
```

Packages under `pkgs/` are written by the baryon-mcp release pipeline on every tagged release, so changes made there by hand are overwritten. Report problems at https://github.com/combor/baryon-mcp/issues.
